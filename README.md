# Programs

Small projects I built at university and in self-study, across several languages.

| Project | Language | What it does |
| --- | --- | --- |
| [Gradient method](C++/Gradient%20Met.cpp) | C++ | Finds the minimum of a two-variable function with the gradient method and step fractionation |
| [Hestenes–Stiefel method](C++/Hestenes%20Stiefel's%20Met.cpp) | C++ | Unconstrained optimisation with the Hestenes–Stiefel conjugate-gradient method |
| [Garage and furniture classes](C++/) | C++ | Object-oriented exercises: classes, inheritance, constructors and stream output |
| [Windows app](C++/Win%20app.cpp) | C++ | Win32 window that keeps a message centred while the window is resized |
| [Encryption methods](Python/Encryption%20methods/) | Python | Caesar, Vigenère and Vernam ciphers (encrypt and decrypt) |
| [Decode text](Python/decode%20text.py) | Python | Reads number–word pairs from a file and decodes the hidden message from a number pyramid |
| [Randomizer](Randomizer/) | HTML, JavaScript | Activity randomizer and holiday-date randomizer that run in the browser |
| [Special Calculator](Special%20Calculator) | Java (Android) | Android app that finds the sum, the sum of negative numbers and the maximum of numbers typed into text fields |
| [Life RPG](Randomizer/life-rpg/) | TypeScript, Next.js, Supabase | Habit tracker that turns daily tasks into game quests with XP and streaks (work in progress) |

## Run them

- **C++:** compile with any C++ compiler, for example `g++ "Gradient Met.cpp" -o gradient`
- **Python:** `python "met Caesar.py"`
- **Randomizer:** open the `.html` files in a browser
- **Life RPG:** see its own README
